# 🎨 팀 구성 PPT 슬라이드 제작 프롬프트

> 아래 프롬프트를 PPT 생성 AI(Gamma, ChatGPT, Gemini 등)에 복사해서 사용하세요.
> 이름 부분(OOO)은 실제 팀원 이름으로 교체해주세요.

---

## 프롬프트

```
프로젝트 팀 구성을 소개하는 발표용 PPT 슬라이드 1장을 제작해줘.
깔끔하고 전문적인 디자인으로 만들어줘. 다크 테마 또는 네이비/딥블루 계열 배경에 화이트 텍스트로 가독성 있게 구성해줘.

### 슬라이드 정보

- 프로젝트명: 하이브리드 데이터 플로우를 활용한 Isaac Sim 및 ROS 2 기반 지능형 물류창고 관제 시스템
- 팀명: 협동3
- 인원: 4명

### 팀원 구성 (카드형 레이아웃으로 4명 가로 배치)

1. **OOO** — BG2 (분류 라인)
   - 담당: 분류 컨베이어 라인 시뮬레이션
   - 주요 기술: Isaac Sim, ROS 2 Topic/Service, 컨베이어 물리 시뮬레이션
   - 아이콘: 📦 또는 컨베이어 벨트 아이콘

2. **OOO** — SG2 (적재·포장 라인)
   - 담당: 로봇 암 적재/포장 공정 시뮬레이션
   - 주요 기술: Isaac Sim, 로봇 암 제어, ROS 2 Action Server
   - 아이콘: 🤖 또는 로봇 암 아이콘

3. **OOO** — AMR (자율주행 이동 로봇)
   - 담당: AMR 자율주행 경로 계획 및 네비게이션
   - 주요 기술: A* 알고리즘, Nav2, ROS 2 Action Client, Redis 위치 동기화
   - 아이콘: 🚗 또는 AGV/AMR 아이콘

4. **윤OO** — 관제탑 (Control Tower)
   - 담당: 중앙 관제 시스템 설계 / 백엔드 / DB / 실시간 스케줄링 / 시뮬레이션 최적화
   - 주요 기술: ROS 2 Humble, PostgreSQL, Redis ZSET, FastAPI, OpenUSD 인스턴싱
   - 아이콘: 🗼 또는 컨트롤 타워 아이콘

### 디자인 요구사항
- 각 팀원을 카드(Card) 형태로 가로 4열 배치
- 각 카드 상단에 역할 아이콘, 중앙에 이름과 역할명, 하단에 주요 기술 키워드 태그
- 슬라이드 상단 타이틀: "👥 팀 구성 — Team Structure"
- 슬라이드 하단에 시스템 흐름을 한 줄로 표시:
  「BG2 분류」→「AMR 이송」→「SG2 적재/포장」→「관제탑 통합 제어」
- 전체적으로 테크/엔지니어링 느낌의 모던한 디자인
- 연결선이나 화살표로 4명의 역할이 하나의 시스템으로 연결되는 것을 시각적으로 표현
```

## 간단 버전 (짧은 프롬프트)

```
물류 자동화 프로젝트 팀 구성 슬라이드 1장 만들어줘. 다크 네이비 배경, 카드형 가로 4열 배치.

팀명: 협동3 | 프로젝트: Isaac Sim + ROS 2 기반 지능형 물류창고 관제 시스템

1. OOO — 📦 BG2 분류 라인 (Isaac Sim 컨베이어 시뮬레이션)
2. OOO — 🤖 SG2 적재·포장 (로봇 암 제어 및 포장 공정)
3. OOO — 🚗 AMR 자율주행 (A* 경로 계획, Nav2 네비게이션)
4. 윤OO — 🗼 관제탑 Control Tower (백엔드/DB/스케줄링/최적화)

하단에 흐름도: BG2 분류 → AMR 이송 → SG2 적재·포장 → 관제탑 통합 제어
```
